# Spice / SCH

MacのブラウザでSPICEネットリストを読み込み、MicroSim PSpice Schematics 8.0のテキスト形式を対象とした実験的な回路図を書き出すWebアプリです。リポジトリをダウンロードし、フォルダ内の **index.html** を開いてください。インストールやサーバー起動は不要です。

## 使い方

1. 「回路例」でRCローパスフィルタかTDA2050簡易モデルを選びます。自分の回路は「ファイルを開く」か、ネットリスト欄への貼り付けで読み込めます。
2. 入力を編集すると部品、配線、ノード数が更新されます。「拡大」で大きな図をスクロールできます。
3. 「回路図を保存」で .sch をダウンロードします。元の回路ファイルはブラウザ内で処理します。

## 入力と出力

先頭行はSPICEの回路タイトルです。R、L、C、独立電圧源（DC、位相指定のないAC、3引数のSIN）、線形の電圧制御電圧源E、.AC DECに対応します。接地ノードは0です。1枚に20部品・24ノードまで扱えます。.PRINTは解析出力の指定として画面に通知し、省略します。未対応の部品・解析命令がある場合は、該当行を示して保存を停止します。

元のネットリストには配置情報が含まれないため、位置と配線経路を生成します。3素子のRCローパスには専用配置、それ以外にはノードごとの縦配線を使います。交差する線は、同一ネットの分岐点にのみ接続します。TDA2050例の増幅器は線形の制御電源モデルです。

## 互換性の確認状況

公開作例のファイル構造を参照して書き出し処理を独自に実装しました。大学指定のWindows版Schematicsでの読み込み・再保存・シミュレーションは未検証です。Cadenceの製品や部品ライブラリは同梱していません。

- [形式を照合したFOSSEEの公開作例と独立したリーダー](https://github.com/FOSSEE/Pspice-Kicad-Converter)
- [TDA2050データシート Figure 4](https://www.st.com/resource/en/datasheet/cd00000131.pdf)

大学の環境での確認にはRC例を使用できます。VAC、1 kΩ、100 nFと接地を確認し、AC解析でoutをプローブしてください。入力振幅1 Vの場合、約1.59 kHzで出力の大きさが約0.707 Vになります。部品値を変更した後に再保存して開き直せれば、編集と保存も検証できます。

## 開発

Node.jsの標準機能で `npm test` と `npm run check` を実行できます。ビルドと実行時依存パッケージはありません。
